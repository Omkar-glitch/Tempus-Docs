# Tempus Documentation

This repository hosts documentation and legal pages for the Tempus app.

## Privacy Policy

The privacy policy is available at [privacy.html](docs/privacy.html).

## GitHub Pages

This site is hosted using GitHub Pages. To set up:

1. Go to your GitHub repository settings
2. Navigate to Pages section
3. Select source: "Deploy from a branch"
4. Select branch: `main` and folder: `/docs`
5. Save

The privacy policy will be available at:
`https://omkar-glitch.github.io/Tempus-Docs/privacy.html`
